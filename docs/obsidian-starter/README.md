# Obsidian starter kit

Sanitized, reusable parts of the RevEng Nexus Obsidian vault: the
[Token Optimization Protocol](00%20-%20Home/Token%20Optimization%20Protocol.md) and the
templates in `08 - Templates/`. No project-state notes, session notes or local paths are
shipped here. Those live only in the private vault.

Create or top up a vault (never overwrites existing files):

```powershell
python scripts/init_obsidian_vault.py "<path to vault>" --dry-run
python scripts/init_obsidian_vault.py "<path to vault>"
```

See [docs/OBSIDIAN_WORKFLOW.md](../OBSIDIAN_WORKFLOW.md) for how the vault is used.
